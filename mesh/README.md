To use the mesh reg_torus, it is necessary to replace the default surfacemesh class file by the altered one provided here (which includes the surfacemesh.reg_torus argument).

The base for the triceratops mesh was obtained from https://quaternius.com/ and edited using Rhino 8. The script surfacepts converts a Rhino SubD to a .csv file which can be imported directly into surfacefun.
